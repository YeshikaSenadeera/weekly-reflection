# Reflection log template

Use this format for `reflection-log.md` (or the memory file). Newest week at the top. Never put personal or sensitive details here.

```
# Weekly Reflection Log

## Character
Name: <character>
Voice card:
- Traits: ...
- How they praise: ...
- How they push: ...
- Pet names / tics: ...
- Emoji style: ...
- Soft mode: ...

## Weeks

### <YYYY-MM-DD>
Action: <one sentence>
Last week's action: done / not done / partly
Lessons:
- <one line>
- <one line>

### <YYYY-MM-DD>
...
```

Keep the last 8 weeks in full. Roll older weeks into one line each under "## Older" so the file stays short and patterns stay visible.
